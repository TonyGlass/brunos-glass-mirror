# Model and configuration references

## Current direct configurator

The current local configurator uses six distinct neutral SVG layout diagrams in
`images/configurations/`: Sliding Door, Swing Door + Fixed Panel, 90° Corner
Enclosure, Fixed Panel / Walk-In, Tub Enclosure, and Not Sure / Recommend for Me.
These diagrams are not photographs, material samples, fabrication drawings, or
claims about a completed Bruno installation. Material is selected separately.
The architectural-glass SVG is also a neutral service illustration.

The research and photo selections below describe the earlier presentation and
are retained as history. They do not describe the current configuration cards.
